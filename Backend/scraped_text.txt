The Greater Chennai Corporation (GCC), established as the Madras Corporation in 1688, stands as India’s oldest municipal body and manages one of the country’s most significant metropolitan areas. This comprehensive guide provides you with the most current and verified information about Chennai’s 200 wards distributed across 15 administrative zones.


Key Fact: Chennai Corporation expanded dramatically in 2011, merging 42 local bodies to increase from 155 to 200 wards, covering an area of 426 square kilometers with over 4.41 million voters.
Understanding Chennai’s Administrative Structure
What are Wards and Zones?
Wards are the smallest administrative units in Chennai’s governance structure, each represented by an elected councillor. Zones are larger administrative divisions that group multiple wards together for efficient management and resource allocation.
Current Structure Overview


Total Wards: 200


Total Zones: 15 (with plans for expansion to 20 zones)


Total Area: 426 square kilometers


Population: Approximately 8.5 million (2024 estimate)


Voters: 4.41 million registered voters

The Greater Chennai Corporation follows constitutional reservation requirements for social justice and women’s empowerment:


26 wards are reserved for Scheduled Castes and Scheduled Tribes

116 wards are unreserved (general category)


2024 Updates: Expansion to 20 Zones
In a significant development, Chief Minister MK Stalin has announced the restructuring of Chennai Corporation from 15 to 20 zones to ensure better resource allocation and management efficiency.
Key Points of the New 20-Zone Structure:


Population-based redistribution using 2023 projections from 2011 census data


Zone 1 will have the maximum 19 wards covering Madhavaram, Ponneri, and Tiruvottiyur constituencies


Zone 19 will be the smallest with 6 wards in Alandur and Sholinganallur areas


Total population: 79.53 lakh across all zones


Property count: 13.82 lakh properties




Important Note: As of August 2024, the 20-zone structure is in the planning phase. The current operational structure remains 15 zones with 200 wards.

Frequently Asked Questions
Q: How often do ward boundaries change?
A: Ward boundaries are typically redrawn during delimitation exercises, usually conducted every 10-15 years based on census data and population changes.
Q: Can I request services from a different ward?
A: Generally, civic services are ward-specific. However, emergency services and some utilities may have cross-ward coverage.
Q: Who represents my ward in the Corporation?
A: Each ward elects one councillor who represents the ward in the Corporation Council and serves as your primary point of contact for local issues.
Q: Are ward numbers permanent?
A: Ward numbers can change during delimitation exercises when boundaries are redrawn. Always verify your current ward number through official channels.

(function () {
  var btn = document.getElementById('float-wa-btn');
  var wrap = document.getElementById('float-share');
  if (!btn || !wrap) return;

  // Set WhatsApp URL dynamically
  function updateLink() {
    var text = encodeURIComponent(document.title + ' — ' + location.href);
    btn.href = 'https://wa.me/?text=' + text;
  }
  updateLink();

  // Show after 300px scroll, hide when near top
  var shown = false;
  window.addEventListener('scroll', function () {
    var shouldShow = window.scrollY > 300;
    if (shouldShow !== shown) {
      shown = shouldShow;
      wrap.style.opacity = shouldShow ? '1' : '0';
      wrap.style.pointerEvents = shouldShow ? 'auto' : 'none';
      wrap.setAttribute('aria-hidden', shouldShow ? 'false' : 'true');
    }
  }, { passive: true });
})();
   
      (() => {
        const canonicalHost = 'chennaicentral.in';
        const pagesHost = 'chennaicentral-in.pages.dev';

        const isInternalHost = (hostname) =>
          hostname === location.hostname ||
          hostname === canonicalHost ||
          hostname.endsWith(`.${canonicalHost}`) ||
          hostname === pagesHost ||
          hostname.endsWith(`.${pagesHost}`);

        const processLink = (link) => {
          const href = link.getAttribute('href');
          if (!href) return;

          let url;
          try {
            url = new URL(href, location.href);
          } catch {
            return;
          }

          if (!['http:', 'https:'].includes(url.protocol) || isInternalHost(url.hostname)) return;

          url.searchParams.set('utm_source', canonicalHost);
          url.searchParams.set('utm_medium', 'referral');
          if (link.getAttribute('href') !== url.href) link.setAttribute('href', url.href);

          const rel = new Set((link.getAttribute('rel') || '').split(/\s+/).filter(Boolean));
          if (!rel.has('nofollow')) {
            rel.add('nofollow');
            link.setAttribute('rel', [...rel].join(' '));
          }
        };

        const processLinksWithin = (node) => {
          if (!(node instanceof Element)) return;
          if (node.matches('a[href]')) processLink(node);
          node.querySelectorAll('a[href]').forEach(processLink);
        };

        document.querySelectorAll('a[href]').forEach(processLink);

        new MutationObserver((mutations) => {
          for (const mutation of mutations) {
            if (mutation.type === 'attributes') {
              processLink(mutation.target);
              continue;
            }
            mutation.addedNodes.forEach(processLinksWithin);
          }
        }).observe(document.documentElement, {
          childList: true,
          subtree: true,
          attributes: true,
          attributeFilter: ['href'],
        });
      })();
